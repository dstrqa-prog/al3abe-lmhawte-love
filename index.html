1. أنشئ مجلداً باسم اللعبة

في مستودع GitHub الخاص بك، أنشئ مجلداً جديداً بجانب ملف index.html الرئيسي، واجعل اسم المجلد هو اسم اللعبة بالعربي أو الإنجليزي (مثلاً: مغامرة ذكرياتنا).

2. ضع ملف اللعبة بداخله

ارفع ملف اللعبة باسم index.html داخل ذلك المجلد مع أي صور أو أصوات خاصة بها.

3. ظهور فوري بدون iframe

ستقوم هذه الصفحة تلقائياً باكتشاف المجلد وعرض اسمه كبطاقة، وعند الضغط عليه يتم جلب اللعبة وتشغيلها بالكامل عبر fetch().
